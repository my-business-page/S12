# D'Seraya Bakes — S12

A custom, mobile-first showcase website created for D'Seraya Bakes, a Singapore home-based bakery.

## Included
- Responsive HTML/CSS/JS
- Mobile navigation
- Scroll reveal animations
- Animated bakery marquee
- Product/menu showcase
- Story section
- Ordering steps
- FAQ accordion
- Floating WhatsApp CTA
- Instagram link
- Pasir Ris collection + delivery information
